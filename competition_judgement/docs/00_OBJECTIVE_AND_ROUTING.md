# 00 — 문제 정의: 경합 후보는 점유 판단의 중간 신호

## 사용자의 의도
1. 경기의 각 시점에서 볼 추적의 유효성 및 선수 집합 구조에 따라 **여러 상황을 구분**한다.
2. 특히 볼이 여러 선수 사이에 튀거나 통제 주체가 불확실할 수 있는 **경합 후보 구간**을 선수 좌표로 탐지한다.
3. 이후 최종 `possession_judgement`(아직 설계·통합 전)에서 상황별 다른 공식을 사용해 H/A/D/X를 결정한다.
4. 선수 집합이 가까이 모이는 정도와 **시간에 따른 접근→집중→분리** 변화를 중심으로 분석한다. 12구역에서 시작해 48구역도 사용해왔으나 구역 안 점유 비율만으로는 한계가 있어 실제 거리 기반 전역 관계를 기본으로 삼는다.

## 시스템 경계
```text
ATD 선수 좌표·팀코드 + 공식 프레임 경계
      |
      +--> 관측·품질 QA
      |
      +--> 선수 간 전역 거리/혼합 연결/팀 구조/시간 변화
                    |
            competition_judgement
         {candidate_score, state, reliability, reason}
                    |
             [미래 통합 단계]
      상황별 점유 추론: 일반 / 경합 후보 / 관측 불충분
                    |
              H / A / D / X
```
현재 구현 범위는 `competition_judgement`까지만이다. 점유 판단의 다른 분기(볼 기반, owner evidence, dead-ball)를 이번 단계에서 변경하지 않는다.

## 의미 구분 — 반드시 지킨다
- `candidate_score`: 자동 계산한 경합 **후보의 상대적 강도**. 확률 아님.
- `candidate` / `not_candidate`: **규칙 충족/미충족**. 실제 경합 정답 라벨 아님.
- `insufficient_observation`: 부족한 관측으로 **판단 보류**. 비경합 아님.
- `H`,`A`: 살아있는 볼의 마지막 통제 점유팀.
- `D`: 경기 중단(Dead ball). 경합과 별개.
- `X`: 점유 예측 기권. 경합·노이즈·공식 비평가 구간의 의미와 동치가 아님.

## 성공 기준
- 공·Smart Tagging·수작업 라벨 없이 선수 좌표로 상황 후보와 근거를 출력한다.
- 199,319프레임 정렬을 보존하고 관측 불충분을 분리한다.
- 같은 경기·같은 설정에서 재현 가능하고 물리적 의미가 설명된다.
- 관측 누락/좌표 노이즈에서 점수·후보 변화량을 보고한다.
- 장기적으로 점유 모델에 투입할 계약을 제공한다. **경합 F1과 공식 spellF1은 현재 산출물만으로 검증되지 않는다.**

## 기각한 오해
- A/B의 13개 기하 특징 복원 Huber가 낮으면 경합도 잘 찾는다는 주장.
- 같은 선수의 source slot이 시계열에서 유지된다는 가정.
- 48구역 내부에 들어온 선수만 서로 근접하다고 계산하는 방법.
- 경합 후보가 곧바로 점유 전환 또는 D라는 가정.
- MTAH 영상에서 수작업으로 확인한 '경합 정답'을 학습/검증에 사용하는 방법.
