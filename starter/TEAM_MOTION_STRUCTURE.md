# 팀별 이동 구조 진단

환경 설치와 프레임 정렬·초기 라벨 생성은 [HALF_ALIGNMENT.md](HALF_ALIGNMENT.md)를 먼저 따른다.

```bash
conda activate mtah2027
python starter/view_team_motion_structure.py
```

입력은 기존 전체 소스 라벨 파일, 최종 프레임 매핑, 원본 ATD다. 이벤트 목록이나
점유권 GT를 읽지 않는다. 두 소스의 non-X 프레임을 기존 재생 순서로 모두 처리한다.
선수 위치·팀·슬롯·라벨 원본과 이전 이동 벡터 영상은 수정하지 않는다.

출력은 비공개 로컬 `data/derived/team_motion_structure/`에만 둔다.

- `team_motion_structure_player.html`: 프레임 탐색 바와 원래 tactical 번호로 탐색하는 로컬 플레이어.
- `team_motion_structure.mp4`: 팀별 진단을 추가한 전체 non-X H.264 영상.
- `team_motion_structure.csv.gz`: 영상 프레임·소스·팀별 모든 진단 수치와 수렴점 추정 상태.
- `tactical_motion_structure.png`, `broadcast_motion_structure.png`: Home/Away별 전체 시계열.
- `frame_timeline.csv`, `report.json`: 원래 프레임 대응, 영상 검증 정보, 설정과 추정 상태별 개수.

## 속도와 관측 처리

정규화 좌표를 경기장 미터 좌표로 바꾼 뒤 원래 소스의 인접 프레임 차분에 FPS를 곱한다.
두 인접 프레임이 non-X·같은 Half이고, 좌표가 유한한 경기장 내부 관측이어야 한다.
순간 좌표 속력이 설정값 12m/s를 넘는 스텝은 이 진단의 집계에서 제외한다.
이를 포함해 유효 스텝 10개가 연속된 경우에만 과거 0.4초 평균 속도를 사용한다.
결측·X·Half 변경·큰 좌표 점프 후에는 연속 관측 조건을 다시 만족해야 한다.

12m/s는 진단용 엔지니어링 기준이며 선수의 보편적 물리 한계나 GT로 정한 값이 아니다.
원본 위치나 속도를 고치지 않고 집계용 사본에만 마스크를 적용한다.
이 기준으로 모든 슬롯 변경을 탐지할 수 있는 것은 아니다.

## 평균 방향과 수렴점

팀 평균 속도는 유효한 슬롯 속도의 산술평균이다. 정지 슬롯도 포함한다.
별도의 방향 일치도 `R`은 속력 0.5m/s 이상인 이동 슬롯들의 단위 방향벡터 평균 길이다.
`R=1`에 가까우면 같은 방향으로 이동한다. 여러 방향에서 한 지점으로 모이면 R이 낮아도
강한 수렴이 가능하다. 수렴점은 이런 경우를 따로 추정한다.

위치 `p_i`, 단위 방향 `u_i`에 대해 직선까지의 수직 잔차를 줄이는 지점 q를 구한다.

```text
min_q sum_i Huber_3m( ||(I - u_i u_i^T)(q - p_i)|| )
```

4회 IRLS를 사용한다. 이동 슬롯이 4개 미만이거나 방향 행렬의 최소/최대 고윳값 비가
0.04 미만이면 점을 추정하지 않는다. 거의 평행한 화살표의 먼 교차점을 표시하지 않기 위함이다.
추정점은 경기장 내부여야 한다. 이어 각 슬롯의 **앞쪽 진행 방향**인지 확인한다.
수직 잔차 5m 이내, 방향 각도 45도 이내인 전방 지지 슬롯이 최소 4개이고,
전체 이동 슬롯의 60% 이상이어야 수렴점을 채택한다. 확산하는 벡터들의 뒤쪽 교차점은 채택하지 않는다.

수렴 강도와 진단용 신뢰도는 다음처럼 정의했다.

```text
C = 지지 비율 × 이동 슬롯들의 평균 max(cos(방향각), 0) × exp(-지지 잔차 RMS / 5m)
Q = C × min(1, 고윳값 비 / 0.2) × min(1, 이동 슬롯 수 / 8)
      / (1 + 근접 슬롯 쌍 수 / max(유효 슬롯 수, 1))
```

둘 다 0~1의 **설명용 지표이며 검증된 확률이 아니다**. 임계값은 공개 GT로 최적화하지 않았다.
추정 불가 프레임의 좌표·C·Q는 빈칸이고, `focus_status`로 원인을 남긴다.
근접 쌍은 0.25m 미만 관측이다. 중복 슬롯을 확정하거나 수작업으로 삭제하지 않는다.
`focus_median_line_eta_s`는 현재 방향·속도가 유지된다는 가정의 최근접 시점 중앙값이며,
실제 도착 시각 예측이 아니다. 공이 유효할 때 수렴점과 공의 거리도 따로 기록한다.

## 압축·확산

유효 속도가 있는 같은 현재 슬롯 집합에서 다음을 계산한다.

```text
쌍 거리 변화율 = mean_ij [ (p_i-p_j)·(v_i-v_j) / ||p_i-p_j|| ]   [m/s]
Hull 면적 변화율 = 1/2 sum_hull [ cross(v_i,p_next) + cross(p_i,v_next) ] [m²/s]
```

음수는 압축, 양수는 확산이다. 팀이 모양을 유지한 채 평행 이동하면 두 변화율은 0이다.
관측 선수 수가 달라진 두 프레임의 면적을 단순 차분하지 않고,
**현재 hull 꼭짓점과 유효 속도**로 면적의 순간 변화율을 계산한다.
정확히 중복된 위치가 있으면 hull 속도가 모호하므로 면적 변화율은 비워 둔다.
`observed_hull_area_m2`와 `valid_vector_hull_area_m2`는 포함 슬롯 집합이 서로 다를 수 있다.

## 영상과 그래프 읽기

가는 화살표는 필터링된 슬롯 속도×1초, 굵은 화살표는 팀 평균 속도×3초 표시 배율이다.
별 마커가 채택된 수렴점이다. 마커가 없어도 평균 이동·압축 지표는 관측 조건에 따라 계산된다.
아래 패널에서 `obs/valid/move`, `R`, `C/Q`, 추정 상태, 쌍 거리·Hull 변화율을 확인한다.

전체 시계열은 영상 시간(X 제거 후 경과 분)을 x축으로 사용하며 전·후반 경계를 표시한다.
옅은 선은 프레임 수치, 진한 선은 가독성을 위한 과거 1초 평균이다.
원본 CSV 수치는 평활화하지 않으며, 수렴점 추정 불가를 0으로 채우지 않는다.

방송 지표는 카메라에 보이는 선수 부분집합의 값이다. 두 소스의 슬롯은 합치지 않는다.
슬롯·팀 오류, 남은 좌표 점프와 기존 고정 시차 정렬의 한계가 남는다.
이 진단을 점유권 정답, 압박 성공 또는 실제 미래 집결의 증거로 바로 해석하지 않는다.
