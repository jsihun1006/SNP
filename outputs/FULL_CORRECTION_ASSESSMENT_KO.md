# 전체 보정 예상 시간과 정확도 근거

기준: 2026-11-15, 한국 시간. 완료된 3분 시험과 기존 전반 검출 기록을 사용했습니다. 이 보고서를 작성하면서 전체 보정을 시작하지는 않았습니다.

## 예상 시간

3분 원본(4,500프레임)의 자동 처리 시간은 파일 생성·수정 시각 기준으로 약 **150초**입니다. 개발, 대기, 시각 검수 시간은 제외한 간접 추정이며 단계별 계측 벤치마크는 아닙니다. 준비 약 21초, 1차 선택 약 12초, 확대 재검출 약 62초, 최종 선택 약 20초, 좌표·영상 출력 및 검사 약 36초가 근거입니다.

| 범위 | 자동 처리 예상 |
|---|---|
| 이미 후보가 있는 전반 전체: 79,467프레임, 약 53분 영상 | **40~70분** |
| 전·후반 보정만: 155,923프레임 | **약 1시간 20분~2시간 20분** |
| 전·후반, 아직 없는 후반 후보 추출 포함 | **약 4시간 20분~5시간 30분** |
| 도입부 등까지 포함한 원본 MP4 전체, 미처리 후보 추출 포함 | **약 5~6시간** |

후반 후보 76,456프레임을 새로 뽑는 데에는 기존 약 7fps 기준 약 3시간이 추가됩니다. 전체 MP4는 164,487프레임이며 현재 전반 후보 외에 85,020프레임이 더 필요합니다. 장면별 난이도·재검출 비율·GPU 상태에 따라 실제 시간은 달라집니다.

현재 시험 코드는 3분 범위, 출력 경로, 한 프레임의 시각 검수 처리가 고정돼 있습니다. 전체 실행 전 범위 일반화와 청크별 처리가 필요하며 그 개발 시간은 위 표에 포함하지 않았습니다. 재학습과 사람/시각 검수도 별도입니다. 전반을 1배속으로 한 번 보는 데만 약 53분이며, 정지·확대·프레임 라벨링까지 하는 전수 검수 시간은 아직 측정하지 않았습니다.

## 정확도는 얼마나 올라가는가

**현재 자료로 정확도 향상률을 계산할 수 없습니다.**

- 4,500프레임 중 선택 3,130프레임(69.56%)은 관측 선택률입니다. 정밀도나 재현율이 아닙니다.
- 확대 재검출 후보를 선택한 155프레임이 모두 정답이라고 검증한 자료는 없습니다.
- 1,370프레임은 검토·미확정입니다. 가림/화면 밖과 실제 검출 누락이 함께 포함돼 있습니다.
- 시각 확인한 19프레임은 모두 원본 후보 중 최고 신뢰도 후보와 최종 좌표가 같습니다. 따라서 이 19프레임은 일부 선택의 타당성을 보여줄 뿐, 최고 신뢰도 선택 기준 대비 개선을 보여주는 표본은 아닙니다.
- ATD는 선택에 참고했으므로 ATD와의 일치도를 독립적인 정확도 검사로 사용하면 안 됩니다.
- 의심도가 가장 높은 구간으로 고른 시험이므로 이 구간의 수치를 경기 전체로 일반화할 수도 없습니다.

정확도 개선은 튜닝에 사용하지 않은 별도 연속 구간의 실제 공 중심과 가시 여부를 라벨링한 후 측정해야 합니다. 같은 프레임에서 원본 검출 후보, 최고 신뢰도 선택 기준, 보정 결과를 비교합니다. 보이는 공의 재현율, 선택한 점의 정밀도, 중심 위치 오차, 분당 잘못 연결한 횟수, 미확정 비율을 따로 보고해야 합니다. 현재의 필터·선택 과정에 따른 후보 감소율을 오탐 감소율로 제시해서는 안 됩니다.

## Git 저장 상태

보정 코드·좌표·검증 보고서·비교 영상은 로컬 `ball-tracking-correction` 브랜치에 커밋했습니다. 영상 등 큰 파일은 Git LFS로 관리합니다. 원본 영상·다운로드 모델·가상환경·캐시와 H 드라이브의 원본 검출 체크포인트는 중복 저장하지 않았습니다.

SNP 원격 저장소는 현재 연결 계정에서 조회되지 않고 Git 인증도 되지 않아 업로드하지 않았습니다. 이 로컬 저장소는 ZIP에서 시작한 작업 사본으로, SNP 원격 저장소의 커밋 이력을 이어받은 저장소는 아닙니다.
