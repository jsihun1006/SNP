# 공 보정 3분 시험 결과

원본 MP4 **00:12:36.76 이상 ~ 00:15:36.76 미만**, 원본 프레임 **[18,919, 23,419)**만 처리했습니다. 총 4,500프레임, 25fps, 180초입니다. 다른 경기 구간의 결과는 수정하지 않았습니다.

## 이 구간을 고른 이유

전반을 4,500프레임 길이의 연속 구간으로 훑어 후보 충돌과 페널티스폿 부근의 반복 관측을 점수화했습니다. 이 구간에는 원본 후보 17,317개, 신뢰도 0.3 이상 후보가 2개 이상인 프레임 2,507개, 페널티스폿 근처 후보가 있는 프레임 999개가 있었습니다.

이 순위는 오탐 **의심도**입니다. 정답 라벨을 대조해 가장 높은 오탐률을 측정한 것은 아닙니다. 경기장 밖이나 homography 결측이라는 이유만으로 오탐 점수를 주지 않았습니다.

## 적용한 보정

1. 영상 특징점으로 카메라 이동을 근사 보정하고, 장면 전환 후보에서 프레임 연결을 초기화했습니다.
2. 앞뒤 프레임의 후보를 함께 비교하여 한 프레임에 최대 하나의 공 관측을 선택했습니다. 선택할 만한 관측이 없는 상태도 허용했습니다.
3. 페널티스폿에 반복되는 점과 광고 영역의 후보에는 감점했습니다. 특정 경기장 위치를 영구적으로 가리지는 않았습니다.
4. 제공된 방송 ATD를 약한 참고 자료로 사용했습니다. 자동 추적 자료이므로 정답으로 간주하지 않았으며, ATD 좌표를 최종 공 좌표로 복사하지 않았습니다.
5. 의심되는 1,092프레임을 대상으로 512픽셀 영역을 입력 1280으로 확대 재검출했습니다. 동일한 YOLO26x 모델과 FP32를 사용했습니다.
6. 최종 표본 19프레임의 선택을 원본 문맥과 확대 영상에서 시각적으로 확인했습니다. 4,500프레임을 모두 정답 라벨로 검증한 것은 아닙니다.

## 파일

- `ball_correction_preview_3min.mp4`: 1280×480, 3분 전체 비교 영상.
- `ball_correction_before_after_3min.mp4`: 1920×720 고화질 비교 영상.
- `corrected_ball_coordinates.csv`: 4,500프레임의 최종 상태와 좌표.
- `frame_decisions.jsonl`: 원본·재검출 후보 및 프레임별 선택 근거.
- `visual_review.json`: 시각적으로 확인한 정확한 표본 프레임 목록.
- `report.json`, `verification.json`: 집계와 파일 검증.

영상 왼쪽의 주황색은 원본 후보 전체, 오른쪽 초록색은 선택한 관측, 오른쪽 주황색은 검토가 필요한 임시 후보입니다. 임시 후보를 확정된 공으로 해석하면 안 됩니다. 좌표 없는 프레임은 보간하지 않았습니다.

CSV의 `pixel_x`, `pixel_y`는 원본 1920×1080 영상 기준입니다. `provisional_pixel_x`, `provisional_pixel_y`는 검토용이며 최종 좌표가 아닙니다. `visual_reviewed`는 표본 시각 검수 여부입니다. `manually_verified`나 모델 신뢰도를 경기 전체의 정답 보증으로 해석하지 마세요.

경기장 좌표는 같은 방송 프레임의 homography 역행렬을 사용한 지면 투영입니다. 공중볼에서는 실제 공 아래 위치와 차이가 날 수 있습니다. 위치를 부드럽게 보이도록 원본 관측을 이동시키거나, 결측 프레임에 추정 좌표를 채우지는 않았습니다.
