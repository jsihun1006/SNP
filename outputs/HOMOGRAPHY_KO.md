# 공 후보 좌표의 경기장 지면 투영

## 입력과 변환

- 공 후보: `H:\data\ball-tracking-results\first_half\candidates.jsonl`
- Homography: `H:\data\broadcast\BAR-ATH_broadcast_homography.csv`
- 원본 방송 프레임: 7,171 ~ 86,637 (79,467프레임)
- 사용 점: 원본 1920×1080 영상의 공 후보 바운딩박스 중심
- 변환: 같은 `source_frame`의 행렬 H를 역변환하여 동차좌표를 정규화합니다. H는 정규화 경기장 좌표(0~1)를 영상 픽셀로 보내는 행렬입니다.
- 미터 변환: 정규화 x에 105.3, y에 68을 곱했습니다. 이는 저장소의 경기장 크기 관례이며 실제 3D 측정 결과는 아닙니다.
- 방송 프레임 번호를 직접 사용했습니다. tactical 정렬이나 ATD 오프셋, 임의의 ±1프레임 이동은 적용하지 않았습니다.

모든 후보를 CSV에 보존했습니다. 경기장 밖 좌표는 경계로 잘라 맞추지 않았으며, 행렬이 없는 프레임을 이전 행렬로 대체하거나 보간하지 않았습니다. 음수 H 오차 지표가 있는 6프레임의 투영값도 CSV에 남겼지만 시각화에서는 제외했습니다.

원본 CSV는 `H:\data\ball-tracking-results\first_half\homography\ball_candidates_pitch.csv`입니다. 이 폴더의 `ball-candidates-pitch.csv.gz`는 같은 CSV의 압축 사본입니다.

주요 열: `source_frame`, `candidate_index`, `pixel_x`, `pixel_y`, `confidence`, `pitch_x_normalized`, `pitch_y_normalized`, `pitch_x_m`, `pitch_y_m`, `inside_pitch`, `status`, `reprojection_error`, `h_quality_known`.

## 시각화와 검증

- 시간별 보기는 전반 전체에서 1초 간격(1fps)으로 표본한 한 프레임의 후보를 표시합니다. CSV에는 표본이 아닌 전체 25fps 후보가 있습니다.
- 누적 분포는 전체 25fps에서 경기장 안으로 변환된 관측을 약 2.51×2.52m 격자로 합산합니다. 신뢰도 조절은 표시 필터이며 원본 데이터는 변경하지 않습니다.
- 원본 영상의 10,000 / 30,000 / 50,000프레임에 경기장 선을 겹쳐 방향과 프레임 연결을 확인했습니다. 제공된 H의 보정 오차로 실제 잔디 선과 일부 차이가 남습니다.
- 좌표를 다시 영상으로 투영한 최대 수치 오차는 약 4.49×10⁻¹⁰픽셀입니다. 이는 역행렬 구현 검증이며, 실제 공 위치의 정확도를 의미하지 않습니다.
- H CSV는 164,488행이고 영상은 164,487프레임입니다. 마지막 여분 행은 이번 전반 구간 밖에 있으므로 사용하지 않았습니다.

## 해석

표시된 점은 공 후보의 **지면 투영**입니다. 공이 공중에 있으면 실제 공의 수직 아래 위치와 달라질 수 있습니다. 로고·마이크 등의 오검출, 경기장 밖의 실제 공, H 보정 오차도 남아 있습니다. 후보를 하나의 확정된 공으로 선택하거나 후보 점들을 검증된 궤적으로 연결하지 않았습니다.
