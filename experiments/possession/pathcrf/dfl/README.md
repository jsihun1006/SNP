# DFL PathCRF 후속 실험 기준

DFL 인플레이 팀 점유 실험에서 다음 네 가지를 공통 모델 구조로 유지한다.

1. **혼합 백본** — Ball Radar 방식의 공간 인코더와 TranSPORTmer 방식의 시간 self-attention을 결합한다. Coarse 단계와 fine 단계를 순서대로 쌓는다.
2. **선수 관계를 두 범위에서 표현** — 매 시점에서 팀별 인코딩(PPE)과 양 팀 전체 인코딩(FPE)을 모두 계산해 결합한다. 두 단계 모두 이 구조를 사용한다.
3. **동적 마스크 CRF** — 후보 점유 엣지와 연속 엣지 사이의 전환을 채점한다. 전환 점수는 경기 문맥에 따라 달라지고, 불가능한 전환은 고정 마스크로 막는다.
4. **Viterbi 디코딩** — CRF 점수와 마스크를 사용해 각 인플레이 에피소드의 최적 엣지 경로를 구한 뒤 홈·원정 팀 점유로 변환한다.

기존 재현은 공식 trial 140 체크포인트를 사용한다. DFL 원본은 25fps이고, 모델은 인플레이 구간을 5fps로 샘플링해 명목상 10초·50시점 창으로 처리한다. 인접 추론 창의 점수를 합친 뒤 에피소드 단위로 디코딩하고 이전 상태를 유지하는 방식으로 25fps 원본 프레임에 맞춰 평가한다. XY 및 Z 보정 실험은 25fps 좌표로 전환 후보를 찾고 5fps CRF의 전환 점수에 반영한다.
