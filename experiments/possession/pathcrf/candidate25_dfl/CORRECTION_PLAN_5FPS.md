# 5fps 오류 유형별 보정안

기준은 J03WR9의 원래 5fps 결과다. 아래는 추가 실험 제안이며 개선 보장이나 신규 실측 결과가 아니다. 보정 모델 학습과 임계값 선택에는 학습 5경기와 검증 J03WQQ만 사용한다. J03WR9는 이미 분석한 홀드아웃이므로 후속 결과는 재사용 홀드아웃 진단으로 표시한다.

## 우선 적용 순서

1. 관측 근거가 있는 경계 스냅. 기존 correction_3은 저장된 재사용 홀드아웃에서 Spell F1 71.81→72.72%, 전환 MAE 252.9→167.1ms, 짧은 점유 재현율 30.85→32.98%였다. 누락 전환은 111→110으로 개선 폭이 작다.
2. 누락 후보 추가 + 방향별 전환 점수 + 국소/전체 재디코딩. 기존 correction_5는 Spell F1은 72.83%였으나 누락은 124개로 늘었다. 동일 보정을 그대로 적용하기보다 누락과 짧은 점유 재현율도 함께 검증해야 한다.
3. 가짜 전환 검증기는 신뢰도가 낮은 일부에만 적용. 기존 검증 실험은 비활성값을 선택했으므로 효과가 확인됐다고 볼 수 없다.

위의 25fps 단독 학습은 이 보정들과 분리한 실험이다. 5fps 보정을 새 25fps 모델에 자동으로 덧붙이지 않는다. 기존 6종 보정의 실제 결과는 CORRECTIONS_5FPS.md에 있다.
