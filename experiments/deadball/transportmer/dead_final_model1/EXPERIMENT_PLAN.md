# Dead Final 1 가중치로 시작하는 TranSPORTmer Model 1

## 1. 실험 조건

| 항목 | 설정 |
|---|---|
| 평가 분할 | DFL 7경기. 평가 경기 전체를 뺀 6경기로 학습하고 1경기로 평가한다. |
| 초기 가중치 | Dead Final 1에서 같은 경기를 제외한 체크포인트의 attention Q/K/V 및 출력 투영 24개 텐서(396,288개 값)를 옮긴다. |
| 분류기 | Model 1, 128차원·16헤드·FFN 512. 9.6초 창을 6.25Hz로 읽는다. 위치, 연속 위치 차분, 좌표 관측 상태를 입력으로 사용한다. |
| 초기화 방식 | 입력층·정규화층·FFN·출력층은 Model 1에서 새로 초기화한다. 옮긴 attention 층도 학습한다. |
| 공 복원 | DFL 공에 목표 40.7%, 평균 6초 길이의 결측을 모사한다. 관측 좌표를 유지하고 결측 위치를 복원한다. J03WR9는 같은 6경기로 만든 기존 공 복원 가중치를 재사용한다. 다른 폴드는 지정된 6경기로 공 복원 모델을 10에폭 학습한다. |
| 데드볼 분류 | 학습률 0.0002, AdamW, 최대 8에폭, 배치 24·마이크로배치 8. 훈련 BCE가 가장 낮았던 체크포인트를 저장한다. |
| 판정 | 복원 궤적을 입력으로 프레임별 확률을 낸 뒤 Model 1의 기존 6보정을 적용한다. 원시 확률과 두 단계의 D 판정을 저장한다. |
| 선택 점수 | 경기별 데드볼 Spell F1의 7경기 평균. IoU 0.3·0.4·0.5·0.6·0.7을 사용한다. 인플레이 Spell F1과 데드볼 프레임 F1도 기록한다. |

초기 체크포인트는 평가 경기 전체만 제외한 상태이므로 내부 검증 경기를 새로 빼서 에폭을 고르는 대신, 미리 정한 에폭 상한과 학습 손실을 사용한다. 평가는 외부 홀드아웃 정답으로 한다. 대회 공개 5분 GT는 학습·설정·모델 선택에서 제외한다.

## 2. 비교와 교체

1. 현재 Dead Final 1의 6보정 + 라인아웃 시작점 고정(데드볼 Spell F1 0.8308)을 기준으로 쓴다.
2. 후보의 보정 후 점수가 기준을 넘으면 같은 설정으로 DFL 7경기 전체에서 공 복원 모델과 제출용 분류기를 학습한다. 분류기는 J03WR9 제외 Dead Final 1 체크포인트에서 초기화한다.
3. 저장된 DFL 14개 하프 CSV·가중치와 BAR–ATH 전술 199,319프레임의 데드볼 특징 CSV를 검증한다. BAR–ATH는 제공된 전술 ATD를 사용한다. 전술 영상에서 채점 구간인 프레임에 `D` 또는 `ALIVE`를 기록하고 밖에는 `X`로 표시한다. 이 출력은 팀 점유 모델에 넣는 데드볼 입력이다.
4. 후보가 기준을 넘고 검증이 통과하면 기존 폴더를 실행 폴더의 `previous_dead_final` 아래에 보관하고, 후보 패키지를 `artifacts/deadball/transportmer/dead_final_1`로 옮긴다.
5. 후보가 기준을 넘지 못하면 기존 모델을 유지하고 후보 점수, DFL 예측, 체크포인트를 실행 폴더에 보관한다.

기존 단일 경기 GPU 로그 기준 J03WR9 첫 평가 약 15–20분, 나머지 6개와 최종 7경기 학습까지 Mac 기준 대략 **4–5시간**으로 추정한다. 새 실행 실측이 나오면 폴드별 실제 소요 시간으로 바꿔 기록한다. 학습 시간 단축 효과는 같은 조건의 무작위 초기화와 별도로 비교해야 한다.
