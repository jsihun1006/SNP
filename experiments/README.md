# 실험 기록

과제 / 모델 / 실행 순서로 실험을 관리한다.

| 과제 | 경로 |
|---|---|
| 인플레이·데드볼 | [deadball](deadball) |
| 소유팀·전환 | [possession](possession) |
| 볼·선수 추적과 정렬 | [tracking](tracking) |

각 실행에 데이터 출처, 분할, seed, 모델 설정, 체크포인트 선택 기준, 후처리 조건, 평가 지표와 재현 명령을 연결한다. 기존 manifest의 실행 당시 경로와 기록은 원본으로 보존한다.

로컬 산출물은 `artifacts/<과제>/<모델>/<실행>/`에 보관한다. 저장된 최적 및 마지막 가중치, 평가 예측과 보정 전후 결과를 보존한다. 새 실행은 별도 실행 경로에 저장한다. 이전 실행 경로 일부는 호환 링크다.

DFL 홀드아웃, 교차검증, 대회 입력에서 얻은 결과는 평가 범위를 표시한다. 서로 다른 평가 집합의 수치는 같은 순위표에 섞지 않는다.
