# 최종 트래킹 코드 검토

현재 소스 모음은 [submission/final_tracking](../../submission/final_tracking/README.md)이다.
사용 코드와 입력/출력 근거는 [확정 경로](FINAL_TRACKING_PIPELINE.md)를 따른다.

이전 `submission_tracking` 원본 ATD baseline은 최종 데이터에 사용되지 않아 현재 제출 대상에서
제외했다. 최종 코드 모음은 로컬 검토본이며 공개·commit·최종 점유 제출을 완료한 상태가 아니다.
코드 안의 기존 객체 검수/고정 판정과 private 데이터·가중치의 공개 범위는 별도 검토해야 한다.
