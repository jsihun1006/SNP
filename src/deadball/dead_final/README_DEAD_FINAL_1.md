# Dead Final 1 · 기존 로컬 실행 기록

이 문서는 이전 경기 단위 실험의 기록이다. 현재 하프 단위 7폴드의 실행 방법은 [README.md](README.md)에 있다. 아래의 이전 재현 명령은 당시 로컬 코드와 산출물을 사용한다.

**Dead Final 1은 원시 `tranSPORTmer_D` 모델이다.** 각 시점의 데드볼 확률이 0.5 이상이면 `D`, 그 미만이면 인플레이로 판정한다. 출력은 `artifacts/deadball/transportmer/dead_final_1/predictions/`에 있다. DFL 홀드아웃 7경기의 가중치를 `artifacts/deadball/transportmer/dead_final_1/weights/`에 저장했다. 각 파일은 해당 경기 전체를 제외하고 학습한 모델이다.

## 실험 계획과 실제 진행

1. DFL 7경기를 경기 단위로 7폴드로 나눴다. 각 폴드는 6경기 학습, 1경기 평가다. 한 경기의 전·후반은 같은 폴드에 둔다. 학습 경기마다 각 하프 중앙의 약 12% 창을 내부 검증에 쓴다. 외부 홀드아웃 경기의 정답은 가중치 선택과 보정 설정에 쓰지 않는다.
2. DFL BallStatus를 학습 정답으로 사용했다. 선수 추적에 결측과 좌표 흔들림을 모사했다. 모델에 시점별 정규화 좌표, 팀 표시, 관측 마스크를 넣고, 공 토큰에는 학습된 결측 표현을 넣었다. 데드볼 분류 손실만 최적화했다.
3. 내부 검증 인플레이 Spell F1으로 가중치를 골라 각 홀드아웃의 양쪽 하프를 예측했다. 겹치는 추론 창의 출력을 확률로 변환한 뒤 창 중앙에 더 높은 가중치를 줘 합쳤다. 각 하프 안에서만 원본 25fps로 선형보간했다. 이미 완료된 첫 3폴드는 저장본을 재사용하고 나머지 4폴드를 이어서 학습했다. 에폭 학습과 내부 검증 실측 합계는 **171.9분**이다.
4. 같은 25fps 원시 확률을 고정하고, 기존 6보정 → 관측 라인아웃 경계 강제 → 강제 조건을 넣은 Viterbi 재디코딩을 누적 비교했다. 선수는 원래 평가와 같은 seed로 모사했고, 공은 DFL의 관측 2D 좌표를 사용했다. 결측 공 좌표는 복원하지 않았다. 보정 단계에는 경기 이벤트나 BallStatus를 전달하지 않았다. 상대 팀 소유권은 평가 범위에 포함되지 않는다. 보정 비교와 산출물 생성에 **17.7초**가 걸렸다.
5. 원시 모델을 Dead Final 1으로 등록했다. 보정한 판정은 비교 결과로 저장했다.

## 비교한 보정

기존 6보정은 기준 전환 비용 40, bias 0, 라인 여유 0m, 강도 1.0, 보너스 0.85로 적용했다.

1. 확인된 라인 이탈과 중단 신호에서 인플레이 → D 전환 비용을 내린다.
2. 확인된 이탈 바로 앞에서 D가 일찍 시작하는 것을 억제한다.
3. 재개 후보에서 D → 인플레이 전환 비용을 내린다.
4. 재개 준비 중에는 D를 유지하고 재개 신호에서는 D를 끝내기 쉽게 한다.
5. 패스·운반 등 인플레이 증거가 있으면 D로 들어가기 어렵게 한다.
6. 짧은 이탈–재개 쌍의 시작과 끝 전환을 쉽게 하고 중간 D에 점수를 준다.

**라인아웃 시작점 추가.** 같은 라인에 대해 바깥 방향 움직임이 확인되고 공 중심이 라인 밖 0.36m 이상에서 2프레임 연속 관측되면 첫 확인 프레임과 이어지는 바깥 관측 프레임을 `D`로 고정한다. 0.36m는 공 반지름 0.11m와 오차 여유 0.25m의 합이다. 직전 플레이가 확인되면 이탈 직전 관측을 인플레이로 고정한다. 이 단계는 기존 6보정 출력에서 해당 프레임만 바꾼다.

**Viterbi 경로변화 추가.** 같은 고정 조건을 6보정의 2상태 디코더에 넣고 하프 전체 경로를 다시 계산한다. 고정 구간 바깥의 앞뒤 판정도 바뀔 수 있다. 별도 IFAB 재개·이탈 킥, 경합, 영상 신호 및 결측 경계 비용 보너스는 이 추가 실험에서 비활성화했다.

## 7경기 평가 결과

F1은 경기별 점수의 평균이다. Spell F1은 데드볼과 인플레이를 각각 구간으로 만들어 IoU 0.3·0.4·0.5·0.6·0.7에서 매칭한 F1을 평균했다. 오탐 프레임과 IoU 0.5 누락은 14개 하프의 합계다.

| 조건 | 데드볼 프레임 F1 | 데드볼 Spell F1 | 인플레이 Spell F1 | 인플레이 오탐 프레임 | 데드볼 누락 |
|---|---:|---:|---:|---:|---:|
| **Dead Final 1 (원시 모델)** | 0.8658 | 0.5435 | 0.5157 | 53,817 | 228 |
| 기존 Viterbi | 0.8702 | 0.6867 | 0.6508 | 48,539 | 262 |
| 기존 Viterbi + 라인아웃 | 0.8984 | 0.7551 | 0.7390 | 48,157 | 201 |
| 6보정 | 0.9211 | 0.8156 | 0.7757 | 29,933 | 151 |
| 6보정 + 라인아웃 시작점 | **0.9311** | **0.8308** | **0.7982** | 30,220 | **136** |
| 6보정 + 라인아웃 시작점 + Viterbi 경로변화 | 0.9303 | 0.8269 | 0.7981 | 31,032 | 143 |

라인아웃 시작점 보정은 6보정에서 8,740프레임을 바꿨다. 8,452프레임의 기존 오답을 고쳤고 288프레임에 새 오답을 만들었다. Viterbi를 다시 계산했을 때 추가로 1,050프레임이 바뀌었다. 156프레임을 고쳤고 894프레임에 새 오답을 만들었다.

과거 0.9067은 PyTorch 2.15.0으로 기록된 원래 실행의 **기존 Viterbi + 라인아웃 데드볼 프레임 F1**이다. 이 패키지는 PyTorch 2.8.0으로 끝낸 재학습의 확률과 가중치를 사용한다.

## 산출물

| 경로 | 내용 |
