# 모델 작업 폴더

## 구조

```text
model/
├── 영상추출/
│   ├── 모델/video_naive/           # YOLO11n 영상 좌표 추출 코드·설명
│   └── 추출csv/video_naive/        # 추출 좌표·프레임 상태·미리보기 (로컬)
├── 점유율계산/
│   ├── 계산알고리즘/
│   │   ├── naive/                  # 주최 측 최근접 선수 baseline
│   │   └── model1/                 # 관측 누락·상태 전환을 반영한 모델
│   └── 성능지표/
│       ├── 모델_성능_비교.csv      # 공개 5분 기준 주요 집계 비교
│       ├── naive/                  # baseline 점수·혼동 행렬 등
│       └── model1/                 # model1 점수·혼동 행렬 등
└── 모델별결과csv/
    ├── naive/                      # predictions·진단 CSV (로컬)
    ├── model1/                     # predictions·진단 CSV (로컬)
    └── video_naive/                # 영상추출/추출csv로 연결
```

영상 모델의 `outputs`, 점유 모델의 `predictions`, `diagnostics`, `reports`,
`scoreboard.csv` 등은 위 분류 폴더로 이어지는 상대 심볼릭 링크다. 코드의 기본 실행 경로를 유지하고 데이터 중복을 줄이기 위해 사용한다.

## 해석

- `video_naive`는 영상에서 사람·공 후보의 좌표를 검출한다. 팀 분류나 점유 판단은 하지 않는다.
- 점유 계산의 naive와 model1은 주최 측 ATD에서 최근접 선수 팀 관측을 사용한다. model1은 그 시간 흐름으로 상태를 추론한다. 이 둘은 `video_naive`의 좌표를 입력으로 쓰지 않는다.
- 공개 5분 성능은 파이프라인 확인용이다. 모델 성능 비교 CSV는 당시 평가 결과의 집계이며 모델 선택·튜닝용이 아니다.
- `모델별결과csv/`와 `영상추출/추출csv/`의 프레임별 좌표·진단·미리보기는 로컬에 보관한다. 대회 제공 데이터 및 이를 재구성할 수 있는 파생 데이터는 공개 Git에 올리지 않는다. 코드·설명과 집계 성능 지표는 Git에 포함한다.
- 이전 실행의 `run_manifest.json` 등에 적힌 절대경로와 코드 해시는 실행 당시의 이력이다. 폴더 이동 후의 경로·코드 해시와 다를 수 있다. 신규 실행 기록은 새 경로로 생성된다.
- 각 모델의 실행법과 환경은 해당 `README.md`를 참고한다. 가중치·가상환경과 원본 데이터는 Git에 포함되지 않으며 필요한 위치와 설치 방법은 영상 모델 README에 있다.
